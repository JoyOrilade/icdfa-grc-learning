# GRC 101 – Introduction to Governance, Risk and Compliance (GRC)

## Overview

This repository contains my coursework, laboratory exercises, practical assignments, and supporting documentation for **GRC 101 – Introduction to Governance, Risk and Compliance**, completed as part of the **International Cybersecurity & Digital Forensics Academy (ICDFA)** programme.

The module established a strong foundation in Governance, Risk, and Compliance (GRC) by combining theoretical learning with practical laboratory exercises covering Linux operations, cybersecurity fundamentals, and risk management.

---

## Learning Objectives

Throughout this module I developed practical knowledge and skills in:

- Governance, Risk and Compliance (GRC) fundamentals
- Information Security principles
- Linux operating system fundamentals
- Risk identification and assessment
- Risk treatment planning
- Security documentation
- Cybersecurity best practices
- Hands-on laboratory exercises
