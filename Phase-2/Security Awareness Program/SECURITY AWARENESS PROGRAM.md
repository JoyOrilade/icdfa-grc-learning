# GRC206 – Security Awareness Program  
## Northbridge Logistics

This folder contains the individual assignment for **GRC206: Design a Security Awareness Program**.

### Assignment Overview
A realistic 12-month Security Awareness Program designed for **Northbridge Logistics**, a fictional organisation with 800 staff across head office, warehouses, and remote sales roles.

The program follows the five-stage lifecycle:
1. **Assess**
2. **Plan**
3. **Deliver**
4. **Measure**
5. **Improve**

### Key Focus Areas
- Invoice fraud / business email compromise (BEC)
- Password reuse and credential hygiene
- Mishandling of regulated customer data
#NAME?
- Measurable behaviour change and continuous improvement within a small security team and modest budget

### Deliverables
- Written report (4–6 pages) covering all five lifecycle stages
- One-page 12-month program calendar
- Short reflection (~150 words)

### Files in this folder
- `Northbridge_Security_Awareness_Program.docx` – Full written report + calendar + reflection
- `Northbridge_Security_Awareness_Program.pdf` – PDF version of the same submission

### Notes
- Scenario facts are taken from the official assignment brief.
- All targets and resource assumptions are clearly labelled as planning proposals (not existing Northbridge results).
- The program is designed to be sustainable by a small security team.
